# Checkpoints do Projeto

## Checkpoint 0 — Escopo e produto

Definir o problema, público-alvo, MVP, fora do MVP, fluxo principal, telas e entidades principais.

## Checkpoint 1 — Repositório profissional

Criar o repositório, documentação inicial, primeira issue, primeira branch, commits pequenos e primeiro pull request.

## Checkpoint 2 — Protótipo visual com dados mockados

Criar uma primeira versão visual do dashboard usando dados falsos, sem integração com Google ainda.

## Checkpoint 3 — Login com Google

Implementar autenticação com Google e sessão do usuário.

## Checkpoint 4 — Listagem de turmas

Buscar e exibir turmas reais do Google Classroom do usuário autenticado.

## Checkpoint 5 — Atividades e materiais

Buscar atividades e materiais das turmas selecionadas.

## Checkpoint 6 — Normalização dos dados

Transformar atividades e materiais em um formato interno único chamado ClassroomItem.

## Checkpoint 7 — Banco de dados e status pessoal

Criar persistência para usuários, turmas, itens e status pessoais.

## Checkpoint 8 — Dashboard real do MVP

Unir autenticação, dados reais do Classroom, status salvos e interface principal.

## Checkpoint 9 — Refinamento para portfólio

Melhorar README, documentação, prints, testes, mensagens de erro e organização do código.

## Checkpoint 10 — Deploy e apresentação

Publicar o projeto e preparar uma explicação curta para entrevistas.
